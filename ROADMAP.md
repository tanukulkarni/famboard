# Home Dashboard Roadmap

Planned features and improvements for the TK & AX household board.

---

## Completed
- [x] Dynamic user system via `/setup`
- [x] Centralized task management on the Manage page
- [x] Shared task viewer on the dashboard
- [x] Dynamic `user.html` pages using `?id=`
- [x] Motivational quote via server-side proxy
- [x] Shared navigation and styling via `style.css`
- [x] Meals API + Manage/Dashboard UI
- [x] Events API + Manage/Dashboard UI (Theo care as events)
- [x] Tracking-focused task UI (rewards de-emphasized)
- [x] Family seed script (`seed_family.py`) for TK / AX / Theo care
- [x] Laptop-friendly default port (5000)
